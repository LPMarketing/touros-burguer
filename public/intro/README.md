# Animação de Abertura — Touros Burguer

Para substituir a animação vetorial interativa do Touro por um vídeo renderizado com transparência (WebM VP9 Alpha ou MP4):

1. Salve os arquivos nesta pasta (ex: `touro-intro.webm` e `touro-intro.mp4`).
2. Atualize `siteConfig.media.introVideoWebmSrc` e `siteConfig.media.introVideoMp4Src` em `src/config/siteConfig.ts`.
